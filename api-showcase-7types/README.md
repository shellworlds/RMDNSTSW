# 🌐 7 API Types Showcase

Complete implementations of:
1. REST API (HTTP/JSON)
2. SOAP API (XML)
3. GraphQL API (Query-based)
4. gRPC API (Binary/HTTP2)
5. WebSocket API (Real-time)
6. Webhook API (Event-driven)
7. RPC API (JSON-RPC/XML-RPC)

## 🚀 Quick Start
docker-compose up --build

## 📡 Test All APIs
